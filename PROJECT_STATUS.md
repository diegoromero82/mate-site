## Hallazgos técnicos priorizados

| Prioridad | Hallazgo | Impacto | Estado |
| --- | --- | --- | --- |
| Alta | El menú móvil consultaba el primer elemento `nav` en vez del contenedor `#mobile-menu`. | Podía alterar la navegación de escritorio y no desplegar el menú correcto. | Resuelto: usa el contenedor específico, estados ARIA y cierre con Escape o al seleccionar un enlace. |
| Alta | Las imágenes Open Graph y Twitter declaradas no estaban presentes en `media/`. | Las previsualizaciones en redes sociales podían fallar. | Resuelto: las rutas apuntan a imágenes existentes y se completaron los metadatos faltantes. |
| Media | Tailwind por CDN coexistía con directivas de CSS que requerían una compilación no configurada. | Los estilos personalizados no eran confiables. | Resuelto localmente: las reglas personalizadas son CSS nativo. Se mantiene el CDN como decisión actual. |
| Media | El formulario usaba `fetch` con `no-cors`. | El navegador no podía confirmar el resultado real antes de informar éxito. | Corregido localmente: valida la respuesta HTTP y evita falsos positivos. Pendiente verificar que Google Apps Script exponga CORS. |
| Media | Había imágenes de más de 3 MiB usadas en Servicios y en el carrusel de aliados. | Afectaba el rendimiento, especialmente en redes móviles. | Resuelto: tres imágenes críticas se redujeron a 0,29–0,42 MiB, el logo de Banca de las Oportunidades pasó de 3,08 MiB a 0,05 MiB y las fotografías se marcaron para carga diferida. |
